# Stadium design assets

Generated with the built-in image generation tool using the original Tippetuppen desktop concept as the visual reference. Decorative only: not archival football photographs or puzzle evidence.

Prompt set: reproduce the original cinematic navy floodlit stadium; XI card with eleven red/green jerseys on a perspective pitch; blue goal and ball; purple anonymous silhouette with blank clue cards; amber stadium with goal. All assets requested without UI, titles, buttons or real player identities. HTML supplies all functional text and controls.

Assets are served locally as WebP. Generated portraits are not used for leaderboard users. Reduced-motion preferences disable card animation.
